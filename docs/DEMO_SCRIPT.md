# Demo video script (~2 min)
`docs/demo.webm` is an auto-recorded walkthrough (`node scripts-demo.js`). To record a voice-over version, follow this script:

1. **Dashboard (0:00)** – KPIs (total, active, hired, hire rate, avg days to hire), stage chart, hiring funnel, position/source breakdowns.
2. **Pipeline (0:25)** – Kanban board; drag a candidate from *Applied* to *Interview*. Stage history is recorded automatically.
3. **Search & filters (0:50)** – Candidates tab: type "react", filter by experience, sort by a column, clear filters.
4. **Add candidate (1:10)** – "+ Add candidate", show validation (duplicate email → error), save.
5. **Candidate detail (1:30)** – Change stage, view history timeline, add a note, edit, delete.
6. **Wrap-up (1:50)** – Mention stack (Node/Express/SQLite, vanilla JS), tests, and deployment on Render/Docker.
